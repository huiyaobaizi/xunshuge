# 寻书阁

基于 [开源阅读（Legado）](https://github.com/gedoor/legado) 二次开发的安卓阅读器。

## 特性

- **3443 个书源** —— 一键导入，覆盖主流站点
- **181 本书单** —— 分类整理，直接照着找
- **干净无广告** —— 无弹窗、无推送、无后台自启
- **换源** —— 章节缺失、乱码时一键切换，进度不丢
- **听书** —— 系统 TTS 朗读
- **简繁转换** —— 一键切换

## 关于书源

书源是公开第三方站点的**索引配置**，本项目**不提供、不存储、不分发任何书籍内容**。

资源仅供学习交流，请支持正版。
